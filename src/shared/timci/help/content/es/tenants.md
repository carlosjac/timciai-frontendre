# Inquilinos

Un inquilino es la organización a la que se asignan usuarios y roles. En el tablero, los inquilinos activos aparecen como Tenants activos.

## Para qué sirve

Sirve para crear una organización, cambiarle el nombre y activarla o desactivarla. Aprobar una solicitud de alta ya crea la organización: use esta pantalla cuando deba crearla usted.

## Lista

La lista muestra el nombre y si está activo. Abra una fila para ver la ficha. Crear abre el alta.

## Alta

Indique el nombre y si queda activo. Un inquilino activo puede usarse en asignaciones.

## Ficha

Puede cambiar el nombre. Desactivar lo deja inactivo: no podrá seleccionarse hasta que lo reactive. No se borra. Un inquilino inactivo no se edita: actívelo desde la ficha.

## Qué puede salir mal

Sin un inquilino activo no hay dónde asignar un rol. La organización interna de la plataforma no es un inquilino de una entidad.
