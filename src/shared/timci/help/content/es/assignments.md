# Asignaciones

Una asignación une un usuario, un inquilino y un rol. Eso es lo que le da el menú al administrador de una entidad.

## Para qué sirve

Sirve para dar acceso a una organización y para quitarlo.

## Lista

La lista muestra el usuario, el inquilino y el rol. Quite una fila cuando esa persona ya no deba operar ahí.

## Alta

Elija el usuario, el inquilino y el rol. Guarde. El usuario pasa a ver el menú de ese rol en esa organización.

## Qué puede salir mal

El usuario y el inquilino tienen que estar activos. Sin esta asignación, el usuario no opera la entidad aunque la cuenta exista.
