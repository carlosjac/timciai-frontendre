# Sesiones

Una sesión es un ingreso que sigue vigente. El tablero cuenta las abiertas.

## Para qué sirve

Sirve para ver quién tiene la sesión abierta y para cerrarla si no debe seguir.

## Lista

La lista muestra el usuario y desde cuándo está abierta. Revocar cierra esa sesión: la persona tiene que volver a entrar. Confirme antes de revocar.
