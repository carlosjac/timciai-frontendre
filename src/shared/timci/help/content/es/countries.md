# Países

Los países se ofrecen al dar de alta una entidad y al cargar domicilios.

## Para qué sirve

Sirve para mantener el catálogo que usan las entidades. Una entidad no crea países: los elige de esta lista.

## Lista

La lista muestra el código y el nombre. Abra una fila para ver la ficha. Crear agrega un país.

## Alta

Indique el código ISO, el nombre y si queda activo.

## Ficha

Puede corregir el código y el nombre. Desactivar deja el país inactivo. Los registros que ya lo usan lo conservan. Un país inactivo no se edita: actívelo desde la ficha.
