# Monedas

Las monedas se ofrecen al configurar una entidad y al registrar operaciones.

## Para qué sirve

Sirve para mantener el catálogo de monedas. La cotización de cada una se ve en Cotizaciones. Una entidad solo opera con las monedas que usted dejó activas y que ella acepta.

## Lista

La lista muestra el código y el nombre. Abra una fila para ver la ficha. Crear agrega una moneda.

## Alta

Indique el código, el nombre y si queda activa.

## Ficha

Puede corregir el código y el nombre. Desactivar deja la moneda inactiva. Las operaciones que ya la usan la conservan. Una moneda inactiva no se edita: actívela desde la ficha.
