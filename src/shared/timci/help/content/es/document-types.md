# Tipos de documento

El tipo de documento identifica a un cliente o a una entidad: por ejemplo, el documento fiscal del país.

## Para qué sirve

Sirve para mantener los tipos que se ofrecen al cargar un documento de persona o de empresa.

## Lista

La lista muestra el nombre, el país y si está activo. Abra una fila para ver la ficha. Crear agrega un tipo.

## Alta

Indique el nombre, el país, si aplica a persona física, persona jurídica o ambas, y, si el país tiene reglas, la regla de validación del número. Deje el tipo activo si debe ofrecerse ya.

## Ficha

Puede corregir el nombre, el país, a quién aplica y la regla de validación. Desactivar deja el tipo inactivo. Un tipo inactivo no se edita: actívelo desde la ficha.
