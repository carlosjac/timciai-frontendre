# Acciones

Una acción es un permiso concreto: ver un menú, listar o modificar un recurso. Los permisos juntan acciones en un rol.

## Para qué sirve

Sirve para ver el catálogo de acciones y para agregar una cuando el producto incorpora una nueva. No cambie códigos que ya usan los roles.

## Lista

La lista muestra el código y la descripción. Use el filtro para encontrar una acción antes de incluirla en un permiso.

## Alta

Indique el nombre y el código. El código es el que el sistema consulta: escríbalo igual que lo espera el producto. Marque Acción global cuando ese permiso se evalúa en las organizaciones del usuario, no solo en la que tiene abierta.
