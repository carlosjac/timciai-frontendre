# Cotizaciones

Cada cotización guarda el valor de una moneda en un momento. El tablero, en Salud, muestra la antigüedad de la última.

## Para qué sirve

Sirve para ver si las monedas tienen un valor reciente. Las operaciones en otra moneda usan esa cotización.

## Lista

La lista muestra la moneda, el valor y la fecha. Ordene por fecha para ver la más nueva. Abra una fila para ver el detalle.

## Ficha

La ficha muestra la moneda, el valor y cuándo se tomó. No se edita desde aquí: es el registro de lo que se cotizó.
