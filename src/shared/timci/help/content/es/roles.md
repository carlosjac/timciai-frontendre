# Roles

Un rol agrupa lo que una persona puede hacer. La asignación lo aplica a un usuario en un inquilino.

## Para qué sirve

Sirve para crear roles, cambiarles el nombre y activarlos o desactivarlos. Lo que cada rol puede hacer se define en Permisos.

## Lista

La lista muestra el nombre y si está activo. Abra una fila para ver la ficha. Crear abre el alta.

## Alta

Indique el nombre. Deje el rol activo si va a asignarlo ya.

## Ficha

Puede cambiar el nombre. Desactivar impide usarlo en asignaciones nuevas. Las asignaciones que ya lo tienen siguen hasta que las quite. Un rol inactivo no se edita: actívelo desde la ficha.
